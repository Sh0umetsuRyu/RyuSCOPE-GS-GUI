# RyuSCOPE GS roadmap (v1.0 baseline)

- **v1.0**: Working Gamescope GUI, Steam/Proton launch paths, MangoApp integration and verified Gamescope FSR toggle; distribute a runnable Linux x86_64 application archive.
- **v1.1**: AFMF-Linux frame-generation backend integration attempt, initially on AMD RADV/RX 7800 XT; confirm output frames, input latency and compatibility; do not present experimental performance as verified.
- **Possible later v1.x**: lsfg-vk alternative frame-generation backend, conditional on compatibility/license/technical evaluation.
- **v2.0**: Full LACT integration including actual GPU telemetry, custom live graphs, capability-aware tuning of clocks/voltage/power/fans, apply/revert and profiles. Not merely read-only monitoring.
- **v3.0**: CPU telemetry and monitoring, the final planned major feature milestone, without automated CPU overclocking.

Physical compatibility testing is AMD-only until real NVIDIA and Intel validation occurs.
