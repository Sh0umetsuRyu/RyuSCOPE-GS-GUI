# RyuSCOPE GS v1.0 | Compatibility and test evidence

> **TESTED ON AMD HARDWARE ONLY**. Tested GPU: **AMD Radeon RX 7800 XT** on CachyOS Linux. NVIDIA and Intel hardware have not been tested. An AMD test result does not guarantee all AMD models.

| Game | Runtime / path | Reported result |
| --- | --- | --- |
| Left 4 Dead 2 | Native Linux via Gamescope | Launched; MangoApp overlay shown; Gamescope FSR visual difference demonstrated |
| Half-Life 2 | Native Linux | Game launch demonstrated |
| Fallout: New Vegas | Proton | Game launch demonstrated |
| Sleeping Dogs: Definitive Edition | Proton | Game launch demonstrated |
| Clair Obscur: Expedition 33 | Proton | Game launch demonstrated |

**Unverified / not a pass:** Need for Speed Heat, Biomutant, and The Elder Scrolls IV: Oblivion Remastered (ES4R). Tests were planned or initiated; no completed pass evidence has been recorded for this release.

The five-game test claims are developer-reported results. Only the Left 4 Dead 2 MangoApp and FSR screenshot comparison have been discussed as specific overlay/scaling evidence. FSR screenshots were not frame-perfect captures and are not a scientific sharpness comparison.

The binary distribution must be smoke-tested on the target machine before publication. No universal Linux distribution or cross-vendor compatibility claim is made.
