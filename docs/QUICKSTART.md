# Quick Start (read this first)

**RyuSCOPE GS v0.5.2 has demonstrated both Native Linux and Proton game launches on its developer's CachyOS system.** This GitHub documentation starter does not include the app's working code yet.

**After the complete app is included**, users will be able to download the repository ZIP and run from its extracted folder:

```sh
bash scripts/check-environment.sh
bash scripts/setup-python.sh
bash scripts/run-local.sh
```

You need Gamescope installed, Steam and at least one game for Steam launches, and a current Python interpreter. The setup step requires a published `requirements.txt`. If the script stops because `main.py` or `requirements.txt` is missing, you're looking at the docs-only starter, not a broken install on your PC.

For full guidance, see [Install & Use](INSTALL_AND_USE.md). First-time SteamOS testers should use [Jesse's Guide](JESSE_TEST_GUIDE.md).


**Compatibility headline:** Native Linux (Half-Life 2) AND Proton (multiple Windows games) launch paths have been demonstrated on the maintainer's CachyOS/AMD desktop. The actual v0.5.2 source must be imported before this documentation package is installable. For beginners, see [INSTALL_AND_USE.md](INSTALL_AND_USE.md).
